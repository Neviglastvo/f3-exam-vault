# Перевірені джерела для ІПММС

Ця сторінка відокремлює два типи джерел. [[F3 ІПММС.docx]] задає **точні питання білетів**, а [[Програма-вступного-іспиту-F3.pdf]] підтверджує теми офіційної програми. Вони не є підручниками, тому фактичні пояснення в конспектах звірено також із першоджерелами нижче; межі такого використання пояснено в [[Як читати джерело]].

## Системний аналіз, моделювання і верифікація

- [[Системний аналіз.pdf#page=4|Цибко Г. Ю., Горошко Ю. В. «Основи системного аналізу», 2025, с. 4–115]] — наданий у сховищі конспект лекцій; основне локальне джерело для систем, процедур аналізу, методів і моделей. Його стисле опрацювання: [[Системний аналіз — стислий конспект]].
- [NASA Systems Engineering Handbook](https://www.nasa.gov/reference/2-0-fundamentals-of-systems-engineering/) — межі системи, вимоги, життєвий цикл, верифікація і валідація.
- [NIST/SEMATECH e-Handbook of Statistical Methods](https://www.itl.nist.gov/div898/handbook/) — ймовірності, регресія, планування та аналіз експериментів.

## Мережі й комп'ютерні системи

- [RFC 1122 — Requirements for Internet Hosts](https://www.rfc-editor.org/rfc/rfc1122) — базова архітектура стеку TCP/IP.
- [RFC 9293 — Transmission Control Protocol](https://www.rfc-editor.org/rfc/rfc9293) — властивості TCP.
- [RFC 8200 — Internet Protocol, Version 6](https://www.rfc-editor.org/rfc/rfc8200) — будова та призначення IP-пакета.
- [RFC 9110 — HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — семантика HTTP.

## Бази даних та інформаційні системи

- [Oracle Database Concepts](https://docs.oracle.com/en/database/oracle/oracle-database/26/cncpt/) — модель СУБД, SQL, транзакції, відновлення та Oracle Database.
- [ISO/IEC 9075:2023 — SQL](https://www.iso.org/standard/76583.html) — стандарт мови SQL; повний текст стандарту є платним, тому в конспектах не наведено неперевірених деталей реалізації.

## Програмування, web і безпека

- [NIST SP 800-115](https://csrc.nist.gov/pubs/sp/800/115/final) — підхід до технічного тестування безпеки.
- [NIST SP 800-30 Rev. 1](https://csrc.nist.gov/pubs/sp/800/30/r1/final) — оцінювання ризику.
- [WHATWG HTML Living Standard](https://html.spec.whatwg.org/) — модель документа HTML і вебплатформи.
- [W3C Web Application Security](https://www.w3.org/TR/webappsec/) — стандарти безпеки вебзастосунків.

## Аналіз даних і оптимізація

- [[Програма-вступного-іспиту-F3.pdf#page=11|Офіційна програма, сторінка 11]] — KDD та інтелектуальний аналіз даних.
- [[Програма-вступного-іспиту-F3.pdf#page=21|Офіційна програма, сторінка 21]] — нелінійна й динамічна оптимізація.
- [NIST/SEMATECH e-Handbook of Statistical Methods](https://www.itl.nist.gov/div898/handbook/) — статистичні оцінки, потрібні для перевірки моделей за даними.

## Як застосовувати посилання

Посилання з конспекту веде до відповідного розділу цієї сторінки. Воно дає змогу перевірити визначення або поглибити тему; не потрібно завчати стандарти замість відповіді на білет.
