# Ейлерові Гамільтонові й планарні графи

> [!summary] Відповідь за 20–30 секунд
> Ейлерова властивість стосується проходження всіх ребер, Гамільтонова — відвідування всіх вершин; планарність — можливість намалювати граф без перетину ребер.

## Суть
- Ейлерів цикл у зв’язному неорієнтованому графі існує тоді й лише тоді, коли всі степені парні; шлях — рівно 0 або 2 непарні вершини.
- Для Гамільтонового циклу немає настільки простого універсального критерію; у програмі згадані достатні умови Дірака та Оре.
- Для зв’язного планарного графа виконується формула Ейлера V−E+F=2.
- Теорема Куратовського пов’язує непланарність з підрозбиттями K5 або K3,3.

## Формули / алгоритм
$V-E+F=2$ для зв’язного планарного графа.

## Іспитовий фокус

- **Що запам'ятати:** Ейлерова властивість стосується проходження всіх ребер, Гамільтонова — відвідування всіх вершин; планарність — можливість намалювати граф без перетину ребер.
- **Типова пастка:** Ейлерів шлях проходить ребра, Гамільтонів — вершини; критерії одного не переносяться на інше.
- **Можливі питання:** «Дайте визначення теми Ейлерові Гамільтонові й планарні графи і поясніть ключовий механізм». «Яке головне обмеження або відмінність від пов'язаного поняття?»
