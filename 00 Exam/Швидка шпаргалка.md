# Швидка шпаргалка

> Це **фінальний прогін**, а не заміна нотаток. Кожен пункт веде в повну коротку нотатку.

## Data Mining

### [[KDD і Data Mining]]
`selection → preprocessing → transformation → Data Mining → interpretation/evaluation`.

### [[Метрики відстані і кластеризація]]
- Euclidean: пряма відстань; Manhattan: сума модулів; cosine: кут/напрям.
- Перед distance-based методами: [[Очищення даних|нормалізація/стандартизація]].

### [[PCA і відбір ознак]]
- Власні вектори коваріації: $\Sigma v_i=\lambda_i v_i$.
- Великі $\lambda_i$ → компонента пояснює більше дисперсії.
- **[[Глосарій#PCA|PCA]] створює нові ознаки**, feature selection залишає частину старих.

### [[K-means]]
1. Обрати $K$ і центроїди.
2. Assign → найближчий центр.
3. Update → середнє точок кластера.
4. Повторити до збіжності.

$$J=\sum_{k=1}^{K}\sum_{x_i\in C_k}\|x_i-\mu_k\|^2$$

### [[Дерева рішень]]
$$H=-\sum p_i\log_2p_i,\qquad Gini=1-\sum p_i^2$$

### [[Bayes KNN і SVM]]
$$P(C\mid x)=\frac{P(x\mid C)P(C)}{P(x)}$$

### [[Класифікація і розбиття вибірки]] / [[Ансамблі моделей]]
- `train` — навчання; `validation` — вибір моделі; `test` — фінальна оцінка.
- bagging: паралельно + bootstrap → менша дисперсія;
- boosting: послідовно виправляє помилки → менший bias.

### [[Оцінювання моделей]]
$$Precision=\frac{[[Глосарій#TP|TP]]}{[[Глосарій#TP|TP]]+[[Глосарій#FP|FP]]},\quad Recall=\frac{[[Глосарій#TP|TP]]}{[[Глосарій#TP|TP]]+[[Глосарій#FN|FN]]}$$
$$[[Глосарій#F1|F1]]=\frac{2[[Глосарій#PR|PR]]}{P+R}$$
$$[[Глосарій#MAE|MAE]]=\frac1n\sum|y-\hat y|,\quad [[Глосарій#MSE|MSE]]=\frac1n\sum(y-\hat y)^2,\quad [[Глосарій#RMSE|RMSE]]=\sqrt{[[Глосарій#MSE|MSE]]}$$

### [[Асоціативні правила]]
$$support=P(A\cap B)$$
$$confidence=P(B\mid A)$$
$$lift=\frac{P(A\cap B)}{P(A)P(B)}$$

## Обчислювальний інтелект

### [[Штучний нейрон і функції активації]]
$$z=w^Tx+b,\qquad y=\varphi(z)$$
- [[Глосарій#ReLU|ReLU]]: $\max(0,z)$
- sigmoid: $1/(1+e^{-z})$

### [[Перцептрон MLP і backpropagation]] / [[Навчання нейромереж і SGD]]
- forward → loss → backprop → update.
- $w\leftarrow w-\eta\nabla_w L$.
- [[Глосарій#XOR|XOR]] не лінійно роздільний → одного перцептрона недостатньо.

### [[Генетичні алгоритми]]
`population → fitness → selection → crossover → mutation → replacement → repeat`

### [[Нечітке виведення]]
Mamdani: `fuzzification → rule evaluation/aggregation → activation → accumulation → defuzzification`.

### [[Нечіткі множини]]
$\mu_A(x)\in[0,1]$ — ступінь належності, **не ймовірність**.

## Дискретна математика

### [[Множини]]
$$|\mathcal P(A)|=2^{|A|}$$

### [[Логіка висловлювань]]
$$p\to q\equiv\neg p\lor q$$
$$\neg\forall xP(x)\equiv\exists x\neg P(x)$$
$$\neg\exists xP(x)\equiv\forall x\neg P(x)$$

### [[Комбінаторика]]
$$P_n=n!$$
$$A_n^k=\frac{n!}{(n-k)!}$$
$$C_n^k=\frac{n!}{k!(n-k)!}$$

### [[Основи теорії графів]]
$$\sum_v\deg(v)=2|E|$$

### [[Ейлерові Гамільтонові й планарні графи]]
- Euler cycle: зв’язний + усі степені парні.
- Euler path: рівно 0 або 2 непарні вершини.
- Планарний зв’язний: $V-E+F=2$.

### [[Дерева MST і найкоротші шляхи]]
- дерево: $|E|=|V|-1$.
- Prim/Kruskal → [[Глосарій#MST|MST]].
- Dijkstra → без від’ємних ваг.
- Bellman–Ford → допускає від’ємні ваги.
- Floyd–Warshall → all pairs.

### [[Максимальний потік]]
$$|f_{max}|=c(C_{min})$$

### [[Формальні мови й автомати]]
- [[Глосарій#DFA|DFA]]: один перехід для символу; [[Глосарій#NFA|NFA]]: множина можливих переходів; за класом мов вони рівносильні.
- регулярний вираз ↔ скінченний автомат ↔ регулярна мова.

## Програмування

### [[Інкапсуляція абстракція наслідування поліморфізм]]
- encapsulation = контроль стану/інваріантів;
- abstraction = суттєвий контракт;
- inheritance = is-a;
- polymorphism = один контракт, різні реалізації.

### [[SOLID GRASP і патерни]]
`S R P · O C P · L S P · I S P · D I P`

### [[UML]]
- structural: class, component, deployment;
- behavioral: use case, sequence, state, activity, communication.

### [[Керування пам'яттю RAII і GC]]
- [[Глосарій#RAII|RAII]]: lifetime ресурсу = lifetime об’єкта.
- refcount: проблема циклів.
- [[Глосарій#GC|GC]]: автоматичне виявлення недосяжних об’єктів.

### [[Синхронізація і помилки конкурентності]]
- mutex: один власник критичної секції;
- semaphore: лічильник дозволів;
- race — результат залежить від interleaving;
- deadlock — всі чекають;
- livelock — всі працюють, ніхто не просувається;
- starvation — хтось не отримує ресурс.

### [[Concurrency і parallelism]] / [[Async await і актори]]
- concurrency = структура незалежних задач; parallelism = фізично одночасне виконання;
- `async/await` = неблокувальне очікування, не гарантія нового потоку;
- actor = ізольований стан + повідомлення.

## Дослідження операцій

### [[Лінійне програмування]] / [[Симплекс-метод]]
- лінійна ціль + лінійні обмеження;
- допустима область опукла;
- оптимум — у крайній точці, якщо існує скінченний оптимум.

### [[Двоїстість у лінійному програмуванні]]
$$c^Tx^*=b^Ty^*$$
за сильної двоїстості та існування оптимумів.

### [[Транспортна задача]]
`початковий план (NW/min-cost/Vogel) → потенціали → оцінки клітин → цикл перерахунку`.

### [[Нелінійна оптимізація]]
$$x_{k+1}=x_k-\alpha_k\nabla f(x_k)$$

### [[KKT і чисельна оптимізація]]
Запам’ятати 4 слова: **primal feasibility → dual feasibility → stationarity → complementary slackness**.

### [[Динамічне програмування]]
`state → action → next state → Bellman recurrence → reuse subproblems`.

### [[Цілочисельне програмування]]
branch-and-bound: `LP-bound → branch → bound/prune`; Gomory: додати відсікання дробового плану.

### [[Багатокритеріальна оптимізація]]
Парето-оптимум: жоден критерій не можна поліпшити без погіршення іншого.

### [[Матричні ігри]]
$$\max_i\min_j a_{ij}\le\min_j\max_i a_{ij}$$
Рівність → сідлова точка.

### [[Марковські процеси]]
$P(X_{t+1}\mid X_t,\ldots,X_0)=P(X_{t+1}\mid X_t)$; стаціонарно: $\pi P=\pi$.

### [[Системи масового обслуговування]]
$$L=\lambda W,\qquad L_q=\lambda W_q$$
