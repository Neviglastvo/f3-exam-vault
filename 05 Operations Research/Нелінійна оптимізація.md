# Нелінійна оптимізація

## Конспект розгорнутої відповіді

- Нелінійна оптимізація шукає мінімум або максимум цільової функції, де сама функція чи обмеження є нелінійними. Задачу задають змінними, цільовою функцією, обмеженнями й допустимою множиною.
- Локальний оптимум найкращий у деякому околі, глобальний — серед усіх допустимих точок. Для опуклої задачі локальний мінімум є глобальним; без опуклості стартова точка й метод можуть привести до різних локальних розв'язків.
- Безумовна задача використовує необхідну умову \(\nabla f(x)=0\) для внутрішньої точки, але цього недостатньо без перевірки типу точки. Умовна задача потребує врахування активних обмежень; для гладких задач застосовують умови Куна—Таккера.
- Градієнтні методи рухаються в напрямі зменшення функції, метод Ньютона також використовує кривину. Їхній вибір залежить від гладкості, розмірності, доступності похідних і вартості обчислень.
- Підсумок має назвати отриману точку, значення функції, допустимість, критерій зупинки та перевірку, чи не залежить результат критично від початкового наближення.
- Варіаційне числення оптимізує не число параметрів, а функцію. Для функціоналу \(J[y]=\int F(x,y,y')dx\) необхідна умова гладкого внутрішнього екстремуму — рівняння Ейлера—Лагранжа \(\partial F/\partial y-d/dx(\partial F/\partial y')=0\), доповнене граничними умовами. Воно дає кандидат, який ще потрібно перевірити.
- **Перевірка:** [[Перевірені джерела для ІПММС#Аналіз даних і оптимізація]].

> [!summary] Відповідь за 20–30 секунд
> Нелінійна оптимізація шукає локальний або глобальний екстремум нелінійної функції з обмеженнями або без них; опуклість робить локальний мінімум глобальним.

## Суть
- Для одновимірного пошуку у програмі згаданий метод золотого перерізу.
- Градієнтні методи використовують перші похідні; напрямок −∇f є напрямком найшвидшого локального спадання.
- Для задач з обмеженнями потрібні умови оптимальності, зокрема [[Глосарій#KKT|KKT]].
- Опукла функція на опуклій області не має «поганих» локальних мінімумів.

## Формули / алгоритм
$x_{k+1}=x_k-\alpha_k\nabla f(x_k)$.

## Іспитовий фокус

- **Що запам'ятати:** Нелінійна оптимізація шукає локальний або глобальний екстремум нелінійної функції з обмеженнями або без них; опуклість робить локальний мінімум глобальним.
- **Типова пастка:** Нульовий градієнт є необхідною, але не завжди достатньою ознакою мінімуму; без опуклості локальний мінімум може не бути глобальним.
- **Розгорнута відповідь:** конспект вище відокремлює локальний і глобальний оптимум, опуклість, обмеження та вибір методу.
