# Нелінійна оптимізація

> [!summary] Відповідь за 20–30 секунд
> Нелінійна оптимізація шукає локальний або глобальний екстремум нелінійної функції з обмеженнями або без них; опуклість робить локальний мінімум глобальним.

## Суть
- Для одновимірного пошуку у програмі згаданий метод золотого перерізу.
- Градієнтні методи використовують перші похідні; напрямок −∇f є напрямком найшвидшого локального спадання.
- Для задач з обмеженнями потрібні умови оптимальності, зокрема KKT.
- Опукла функція на опуклій області не має «поганих» локальних мінімумів.

## Формули / алгоритм
$x_{k+1}=x_k-\alpha_k\nabla f(x_k)$.

## Іспитовий фокус

- **Що запам'ятати:** Нелінійна оптимізація шукає локальний або глобальний екстремум нелінійної функції з обмеженнями або без них; опуклість робить локальний мінімум глобальним.
- **Типова пастка:** Нульовий градієнт є необхідною, але не завжди достатньою ознакою мінімуму; без опуклості локальний мінімум може не бути глобальним.
- **Можливі питання:** «Дайте визначення теми Нелінійна оптимізація і поясніть ключовий механізм». «Яке головне обмеження або відмінність від пов'язаного поняття?»
