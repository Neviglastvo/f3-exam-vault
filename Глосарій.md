# Глосарій скорочень

Натисни на скорочення в нотатці, щоб перейти сюди. Англійська повна назва подана там, де вона є усталеною; після тире — коротке пояснення українською.

Повернутися до [[START HERE|стартової сторінки]] або до [[F3 — Карта екзамену|карти іспиту]].

## Навігація та джерела

### F3
Позначення вступного фахового іспиту в цій базі. У програмі, що є джерелом для vault, повну розшифровку цього коду не наведено.

### MOC
*Map of Content* — навігаційна сторінка, що збирає нотатки одного розділу й показує порядок навчання.

### P0
Найвищий пріоритет: опанувати перед першим проходом.

### P1
Другий пріоритет: деталі, порівняння та винятки після P0.

### P2
Третій пріоритет: оглядовий матеріал після P0 і P1.

### PDF
*Portable Document Format* — формат файлу, у якому збережено вихідну програму іспиту.

## Інформаційні системи, мережі та безпека

### DB
*Database* — база даних: організована сукупність взаємопов'язаних даних.

### DBMS
*Database Management System* — система керування базами даних.

### DDL
*Data Definition Language* — підмножина SQL для визначення структури бази даних, наприклад `CREATE` і `ALTER`.

### DML
*Data Manipulation Language* — підмножина SQL для читання та зміни даних, наприклад `SELECT`, `INSERT`, `UPDATE`, `DELETE`.

### ACID
*Atomicity, Consistency, Isolation, Durability* — властивості транзакції: атомарність, узгодженість, ізоляція та довговічність.

### ER
*Entity Relationship* — концептуальна модель «сутність—зв'язок» для проєктування баз даних.

### LAN
*Local Area Network* — локальна обчислювальна мережа в межах обмеженої території.

### WAN
*Wide Area Network* — глобальна мережа, що з'єднує віддалені мережі.

### TCP/IP
*Transmission Control Protocol / Internet Protocol* — базовий стек мережевих протоколів Інтернету; TCP і IP мають різні функції.

### TCP
*Transmission Control Protocol* — транспортний протокол надійної впорядкованої доставки потоку байтів.

### UDP
*User Datagram Protocol* — транспортний протокол дейтаграм без гарантій доставки або порядку.

### IP
*Internet Protocol* — мережевий протокол адресації та маршрутизації пакетів між мережами.

### HTTP
*Hypertext Transfer Protocol* — прикладний протокол обміну веб-запитами й відповідями.

### HTTPS
*Hypertext Transfer Protocol Secure* — HTTP, захищений транспортом TLS.

### DNS
*Domain Name System* — розподілена система зіставлення доменних імен із мережевими даними, зокрема IP-адресами.

### API
*Application Programming Interface* — визначений контракт взаємодії між програмними компонентами.

### IDE
*Integrated Development Environment* — інтегроване середовище розробки.

### CIA
*Confidentiality, Integrity, Availability* — тріада властивостей інформаційної безпеки: конфіденційність, цілісність, доступність.

### P2P
*Peer-to-Peer* — однорангова архітектура, де вузли можуть надавати й споживати ресурси.

### TLS
*Transport Layer Security* — криптографічний протокол захисту даних під час передавання.

### DHCP
*Dynamic Host Configuration Protocol* — протокол автоматичного надання вузлу мережевих параметрів, зокрема IP-адреси.

### SMP
*Symmetric Multiprocessing* — багатопроцесорна організація зі спільною пам'яттю та рівноправними процесорами.

### NUMA
*Non-Uniform Memory Access* — архітектура, де час доступу до пам'яті залежить від її розміщення відносно процесора.

### HTML
*HyperText Markup Language* — мова розмітки структури веб-документа.

### CSS
*Cascading Style Sheets* — мова опису подання веб-документа.

### URL
*Uniform Resource Locator* — адреса ресурсу в мережі.

### JIT
*Just-In-Time compilation* — компіляція коду під час виконання програми.

## Інтелектуальний аналіз даних

### AI
*Artificial Intelligence* — штучний інтелект.

### ML
*Machine Learning* — машинне навчання.

### KDD
*Knowledge Discovery in Databases* — повний процес пошуку знань у даних; Data Mining є лише одним із його етапів.

### JSON
*JavaScript Object Notation* — текстовий формат обміну структурованими даними.

### SQL
*Structured Query Language* — мова запитів до реляційних баз даних.

### OLAP
*Online Analytical Processing* — засоби багатовимірного аналітичного опрацювання даних.

### PCA
*Principal Component Analysis* — метод головних компонент для зменшення розмірності.

### K-means
Алгоритм кластеризації, що розподіляє об’єкти навколо (k) центрів; «K» означає кількість кластерів, а не окрему абревіатуру.

### DBSCAN
*Density-Based Spatial Clustering of Applications with Noise* — кластеризація за щільністю, яка може позначати шум.

### KNN
*k-Nearest Neighbors* — метод класифікації або регресії за найближчими сусідами. Запис **K-NN** означає те саме.

### SVM
*Support Vector Machine* — метод, що будує роздільну межу з максимальним зазором між класами.

### ID3
*Iterative Dichotomiser 3* — алгоритм дерева рішень, що використовує information gain.

### C4.5
Наступник ID3: алгоритм дерева рішень, який використовує gain ratio та підтримує неповні дані.

### CART
*Classification and Regression Trees* — підхід до побудови дерев класифікації та регресії.

### AdaBoost
*Adaptive Boosting* — метод boosting, який послідовно посилює вагу складних для класифікації прикладів.

### XGBoost
*eXtreme Gradient Boosting* — реалізація градієнтного бустингу над деревами рішень.

### LightGBM
*Light Gradient-Boosting Machine* — реалізація градієнтного бустингу, оптимізована для великих даних.

### CatBoost
*Categorical Boosting* — градієнтний бустинг, що спеціально підтримує категоріальні ознаки.

### OOB
*Out-of-Bag* — приклади, не включені до конкретної bootstrap-вибірки; ними можна оцінювати ансамбль.

### FP-Growth
*Frequent Pattern Growth* — алгоритм пошуку частих наборів без масової генерації кандидатів.

### FP-tree
*Frequent Pattern tree* — компактна структура, яку використовує FP-Growth.

### TP
*True Positive* — об’єкт позитивного класу, правильно передбачений як позитивний.

### FP
*False Positive* — негативний об’єкт, помилково передбачений як позитивний.

### TN
*True Negative* — об’єкт негативного класу, правильно передбачений як негативний.

### FN
*False Negative* — позитивний об’єкт, помилково передбачений як негативний.

### F1
*F1 score* — гармонічне середнє Precision і Recall.

### MAE
*Mean Absolute Error* — середня абсолютна похибка.

### MSE
*Mean Squared Error* — середня квадратична похибка.

### RMSE
*Root Mean Squared Error* — корінь із середньої квадратичної похибки.

### ROC
*Receiver Operating Characteristic* — крива співвідношення true-positive rate і false-positive rate за різних порогів.

### PR
*Precision–Recall* — крива або простір метрик Precision і Recall; корисні для оцінювання рідкісного позитивного класу.

### AUC
*Area Under the Curve* — площа під кривою; без уточнення може стосуватися ROC або PR-кривої.

### ROC-AUC
Площа під ROC-кривою; узагальнена міра здатності моделі ранжувати класи.

### PR-AUC
*Precision–Recall Area Under the Curve* — площа під Precision–Recall кривою; особливо інформативна за сильного дисбалансу класів.

### R²
Коефіцієнт детермінації — частка варіації цільової змінної, яку пояснює регресійна модель.

## Обчислювальний інтелект

### NN
*Neural Network* — нейронна мережа.

### MLP
*Multilayer Perceptron* — багатошаровий перцептрон.

### ReLU
*Rectified Linear Unit* — функція активації \(\max(0, z)\).

### SGD
*Stochastic Gradient Descent* — стохастичний градієнтний спуск.

### SOM
*Self-Organizing Map* — самоорганізовна карта, що відображає дані на низьковимірну сітку.

### RBF
*Radial Basis Function* — радіально-базисна функція.

### CNN
*Convolutional Neural Network* — згорткова нейронна мережа.

### RNN
*Recurrent Neural Network* — рекурентна нейронна мережа.

### PSO
*Particle Swarm Optimization* — оптимізація роєм частинок.

### ACO
*Ant Colony Optimization* — оптимізація мурашиною колонією.

### TSP
*Travelling Salesperson Problem* — задача комівояжера.

### ANFIS
*Adaptive Neuro-Fuzzy Inference System* — адаптивна нейро-нечітка система виведення.

## Дискретна математика

### DFA
*Deterministic Finite Automaton* — детермінований скінченний автомат.

### NFA
*Nondeterministic Finite Automaton* — недетермінований скінченний автомат.

### DNF
*Disjunctive Normal Form* — диз’юнктивна нормальна форма.

### CNF
*Conjunctive Normal Form* — кон’юнктивна нормальна форма.

### XOR
*Exclusive OR* — «виключне або»: істинне тоді й лише тоді, коли істинний рівно один операнд.

### GF(2)
*Galois Field of order 2* — поле з двох елементів, зазвичай \(\{0,1\}\), з арифметикою за модулем 2.

### MST
*Minimum Spanning Tree* — мінімальне остовне дерево графа.

### BFS
*Breadth-First Search* — пошук у ширину.

## Програмування

### OOP
*Object-Oriented Programming* — об’єктно-орієнтоване програмування.

### OOA
*Object-Oriented Analysis* — об’єктно-орієнтований аналіз предметної області.

### OOD
*Object-Oriented Design* — об’єктно-орієнтоване проєктування програмного рішення.

### UML
*Unified Modeling Language* — уніфікована мова моделювання.

### SOLID
Набір п’яти принципів об’єктно-орієнтованого проєктування: SRP, OCP, LSP, ISP і DIP.

### SRP
*Single Responsibility Principle* — принцип єдиної відповідальності.

### OCP
*Open–Closed Principle* — принцип відкритості для розширення і закритості для модифікації.

### LSP
*Liskov Substitution Principle* — принцип підстановки Лісков.

### ISP
*Interface Segregation Principle* — принцип розділення інтерфейсів.

### DIP
*Dependency Inversion Principle* — принцип інверсії залежностей.

### GRASP
*General Responsibility Assignment Software Patterns* — шаблони призначення відповідальностей у програмному дизайні.

### GoF
*Gang of Four* — автори класичної книги про шаблони проєктування; назва також позначає її каталог патернів.

### RAII
*Resource Acquisition Is Initialization* — зв’язування часу життя ресурсу з часом життя об’єкта.

### GC
*Garbage Collection* — автоматичне керування пам’яттю.

### RTTI
*Run-Time Type Information* — інформація про фактичний тип під час виконання програми.

### CPU
*Central Processing Unit* — центральний процесор.

### RAM
*Random Access Memory* — оперативна пам'ять для даних і коду, з якими система працює безпосередньо.

### GPU
*Graphics Processing Unit* — графічний або обчислювальний прискорювач для масово паралельних операцій.

## Дослідження операцій

### LP
*Linear Programming* — лінійне програмування.

### NW
*Northwest Corner method* — метод північно-західного кута для побудови початкового плану транспортної задачі.

### KKT
Умови Каруша–Куна–Такера (*Karush–Kuhn–Tucker conditions*) для оптимізації з обмеженнями.

### BFGS
*Broyden–Fletcher–Goldfarb–Shanno* — квазіньютонівський метод оптимізації.

### AHP
*Analytic Hierarchy Process* — метод аналізу ієрархій Сааті для багатокритеріального вибору.

### DP
*Dynamic Programming* — динамічне програмування.

### M/M/1
Позначення базової моделі черги: пуассонівський потік заявок, експоненційний час обслуговування та один канал обслуговування.
