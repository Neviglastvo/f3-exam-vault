# Типи даних і Text Mining

> [!summary] Відповідь за 20–30 секунд
> Метод аналізу залежить від структури та природи даних: структуровані, напівструктуровані, неструктуровані, часові, просторові й текстові.

## Суть
- Структуровані дані мають явну схему; напівструктуровані — часткову; неструктуровані — ні.
- Часові ряди мають порядок у часі, просторові дані — геометричні/топологічні зв’язки.
- Text Mining переносить ідеї Data Mining на текстову інформацію після її представлення у числовому просторі ознак.

## Іспитовий фокус

- **Що запам'ятати:** Метод аналізу залежить від структури та природи даних: структуровані, напівструктуровані, неструктуровані, часові, просторові й текстові.
- **Типова пастка:** Формат зберігання не дорівнює природі даних: JSON може бути напівструктурованим, а текст усередині поля — неструктурованим.
- **Можливі питання:** «Дайте визначення теми Типи даних і Text Mining і поясніть ключовий механізм». «Яке головне обмеження або відмінність від пов'язаного поняття?»
