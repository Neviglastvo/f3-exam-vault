# KDD і Data Mining

## Конспект розгорнутої відповіді

- KDD — повний процес перетворення даних на корисні та перевірені закономірності. Data Mining — його аналітичний етап: застосування алгоритмів для пошуку моделей і залежностей.
- Типовий цикл: визначити задачу й критерій успіху → зібрати та інтегрувати дані → очистити й перетворити їх → відібрати ознаки → застосувати метод → оцінити результат → інтерпретувати та впровадити. Повернення на попередні кроки є нормальною частиною процесу.
- Основні задачі: класифікація призначає об'єкт класу; регресія прогнозує числову величину; кластеризація групує без готових міток; пошук асоціацій знаходить спільні закономірності; виявлення аномалій шукає нетипові об'єкти.
- Модель не стає знанням лише через хорошу метрику: її перевіряють на даних, що не використовувалися для навчання, оцінюють змістовність, зміщення, стабільність і межі застосування.
- Data Mining не дорівнює простому пошуку в БД: запит повертає збережені факти, а аналіз виводить закономірність за даними та припущеннями методу.
- Об'єкт — одиниця спостереження, атрибут — його властивість, вибірка — набір об'єктів. Залежна змінна є результатом, який пояснюють або прогнозують; незалежні змінні — фактори. Номінальна шкала лише розрізняє категорії, порядкова додає порядок, інтервальна має осмислену різницю, шкала відношень має природний нуль.
- **Перевірка:** [[Перевірені джерела для ІПММС#Аналіз даних і оптимізація]].

### Дані, об’єкт, атрибут, вибірка і змінні

- **Об'єкт** — одна одиниця спостереження: наприклад, клієнт, замовлення або вимірювання датчика. **Атрибут** (ознака) — його властивість: вік клієнта, сума замовлення, температура. **Вибірка** — набір об'єктів, на якому виконують аналіз.
- У задачі з учителем **залежна змінна** \(y\) — ціль, яку пояснюють або прогнозують, а **незалежні змінні** \(X\) — вхідні ознаки. Наприклад, ціна житла — \(y\), площа й район — \(X\). У кластеризації готової цільової змінної немає.

### Типи шкал вимірювання

| Шкала | Що дозволяє | Приклад |
| --- | --- | --- |
| Номінальна | Лише розрізнити категорії; порядку немає. | колір, місто |
| Порядкова | Порівняти «вище/нижче», але не різницю між рівнями. | низький / середній / високий ризик |
| Інтервальна | Порівнювати різниці; природного нуля немає. | температура у °C |
| Відношень | Порівнювати різниці й відношення; нуль означає відсутність величини. | маса, кількість покупок |

- Шкала визначає допустимі операції та метрики. Наприклад, середнє арифметичне категорій кольору не має змісту, а числове кодування категорії не робить її шкалою відношень.

### Методи та стадії Data Mining

- Основні методи: **класифікація** і **регресія** прогнозують мітку або число за відомими прикладами; **кластеризація** групує об'єкти без готових міток; **асоціативні правила** шукають часті співзустрічі; **виявлення аномалій** знаходить нетипові спостереження.
- Стадії KDD: сформулювати задачу й критерій успіху → зібрати та інтегрувати дані → очистити й перетворити → відібрати ознаки → застосувати метод → оцінити на даних, не використаних для навчання → інтерпретувати й впровадити результат. Повернення на попередній етап є нормальною частиною циклу.
- Data Mining — не «автоматична істина»: закономірність треба перевірити метрикою, змістом, стійкістю та межами застосування.

> [!summary] Відповідь за 20–30 секунд
> [[Глосарій#KDD|KDD]] — повний процес отримання знань із даних, а Data Mining — його етап пошуку закономірностей. Об'єкт є одиницею спостереження, атрибут — її властивістю, а вибірка — набором об'єктів. Методи обирають за задачею: класифікація й регресія працюють із ціллю, кластеризація — без неї.

## Суть
- Типові задачі: класифікація, кластеризація, асоціації, прогнозування.
- Етапи [[Глосарій#KDD|KDD]]: вибір даних → передобробка → трансформація → Data Mining → інтерпретація/оцінювання.
- Data Mining відрізняється від класичного статистичного аналізу та [[Глосарій#OLAP|OLAP]] акцентом на автоматизованому пошуку нетривіальних закономірностей.

## Іспитовий фокус

- **Що запам'ятати:** [[Глосарій#KDD|KDD]] — повний процес виявлення знань у даних; Data Mining — центральний етап, де алгоритми знаходять закономірності.
- **Типова пастка:** Не ототожнювати Data Mining з усім [[Глосарій#KDD|KDD]]: це лише один етап повного процесу.
- **Розгорнута відповідь:** конспект вище визначає KDD і Data Mining, повний цикл роботи та основні задачі аналізу.
