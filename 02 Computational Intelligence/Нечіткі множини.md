# Нечіткі множини

> [!summary] Відповідь за 20–30 секунд
> У нечіткій множині належність — не лише 0 або 1, а число від 0 до 1; це дає формальний апарат для нечітких понять на кшталт «висока температура».

## Суть
- Функція належності μ(x) задає ступінь належності елемента.
- У програмі: трикутна, трапецієподібна, гаусова, дзвоноподібна функції; носій, ядро, α-зріз.
- Нечіткі числа й лінгвістичні змінні дозволяють працювати з людськими категоріями.
- Операції над нечіткими множинами узагальнюють звичайні перетин/об’єднання/доповнення.

## Іспитовий фокус

- **Що запам'ятати:** У нечіткій множині належність — не лише 0 або 1, а число від 0 до 1; це дає формальний апарат для нечітких понять на кшталт «висока температура».
- **Типова пастка:** Ступінь належності не є ймовірністю: він описує міру відповідності нечіткому поняттю.
- **Можливі питання:** «Дайте визначення теми Нечіткі множини і поясніть ключовий механізм». «Яке головне обмеження або відмінність від пов'язаного поняття?»
