# SOM RBF CNN і RNN

> [!summary] Відповідь за 20–30 секунд
> Програма охоплює кілька спеціалізованих архітектур: SOM — самоорганізація без учителя, RBF — радіально-базисні функції, CNN — просторові дані, RNN — послідовності.

## Суть
- SOM Кохонена проектує багатовимірні дані на карту зі збереженням топологічної близькості.
- RBF використовує локальні радіальні базисні функції та має інтерполяційні властивості.
- CNN експлуатує локальні фільтри й спільні ваги; RNN переносить прихований стан уздовж послідовності.
