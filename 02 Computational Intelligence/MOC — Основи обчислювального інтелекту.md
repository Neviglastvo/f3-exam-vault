# MOC — Основи обчислювального інтелекту

> Частина офіційної програми: сторінки **12–14**. Це навігаційна сторінка, а не окрема тема.

## Як проходити

1. Спочатку **P0** — уміти дати 20–30 секундну відповідь без підглядання.
2. Потім **P1** — деталі, порівняння, винятки; **P2** — після ядра, але не пропускати.
3. Після блоку пройти [[Checklist повторення]] і [[Тренування — 30 тестів]]. Загальний маршрут — [[Що вчити зараз]].

## P0 — ядро

- [ ] [[Обчислювальний інтелект]] — Обчислювальний інтелект об’єднує нейронні мережі, нечіткі системи та еволюційні обчислення для адаптивного розв’язання складних задач, особливо за невизначеності.
- [ ] [[Штучний нейрон і функції активації]] — Штучний нейрон зважує входи, додає bias і пропускає суму через функцію активації, яка задає нелінійність моделі.
- [ ] [[Перцептрон MLP і backpropagation]] — Перцептрон розділяє лише лінійно роздільні класи; MLP з нелінійними прихованими шарами долає це обмеження, а backpropagation обчислює градієнти помилки по шарах.
- [ ] [[Навчання нейромереж і SGD]] — Навчання мережі — мінімізація функції втрат; стохастичний градієнтний спуск оновлює ваги за окремими прикладами або mini-batch, а backprop дає потрібні градієнти.
- [ ] [[Генетичні алгоритми]] — Генетичний алгоритм еволюціонує популяцію закодованих розв’язків за fitness-функцією через селекцію, схрещування, мутацію та заміщення.
- [ ] [[Нечіткі множини]] — У нечіткій множині належність — не лише 0 або 1, а число від 0 до 1; це дає формальний апарат для нечітких понять на кшталт «висока температура».
- [ ] [[Нечітке виведення]] — Нечітке виведення перетворює правила IF–THEN і нечіткі ступені належності на результат; Mamdani зазвичай завершується дефазифікацією.

## P1 — другий прохід

- [ ] [[SOM RBF CNN і RNN]] — Програма охоплює кілька спеціалізованих архітектур: SOM — самоорганізація без учителя, RBF — радіально-базисні функції, CNN — просторові дані, RNN — послідовності.

## P2 — огляд після ядра

- [ ] [[Ройовий інтелект]] — Ройові алгоритми отримують глобальну поведінку з простих локальних правил багатьох агентів: PSO імітує рух частинок, ACO — феромонні сліди мурах.
- [ ] [[ANFIS і гібридні системи]] — Гібридні інтелектуальні системи поєднують сильні сторони різних підходів; ANFIS представляє нечітку систему у формі мережі й навчає її параметри.
