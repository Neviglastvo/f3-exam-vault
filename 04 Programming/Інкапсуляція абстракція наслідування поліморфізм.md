# Інкапсуляція абстракція наслідування поліморфізм

## Конспект розгорнутої відповіді

- Інкапсуляція об'єднує стан і операції над ним та приховує внутрішнє подання за чітким інтерфейсом. Її мета — зберігати інваріанти об'єкта й зменшувати залежність клієнтського коду від реалізації.
- Абстракція залишає в моделі лише властивості, важливі для задачі. Клас або інтерфейс задає контракт поведінки; конкретна реалізація визначає, як його виконано.
- Наслідування описує відношення «є різновидом»: похідний клас успадковує контракт базового та може спеціалізувати поведінку. Воно не є механізмом простого повторного використання коду, якщо підстановка базового типу порушує очікування клієнта.
- Поліморфізм дозволяє працювати з об'єктами через спільний тип, а конкретну реалізацію обрати під час виконання або компіляції залежно від механізму мови. Це відокремлює клієнта від набору конкретних класів.
- Приклад: інтерфейс `Payment` задає операцію оплатити, різні реалізації виконують її по-своєму; клієнт залежить від контракту, а не від конкретного способу оплати.
- **Перевірка:** [[Перевірені джерела для ІПММС#Програмування, web і безпека]].

> [!summary] Відповідь за 20–30 секунд
> Чотири базові ідеї ООП: інкапсуляція приховує внутрішній стан, абстракція залишає суттєве, наслідування повторно використовує/уточнює контракт, поліморфізм дає один інтерфейс для різних реалізацій.

## Суть
- Інкапсуляція ≠ просто private: головне — захист інваріантів через контрольований інтерфейс.
- Абстракція відокремлює «що робить» від «як реалізовано».
- Наслідування задає відношення is-a і має зберігати контракт базового типу.
- Поліморфізм дозволяє викликати однакову операцію для об’єктів різних конкретних типів.

## Іспитовий фокус

- **Що запам'ятати:** Чотири базові ідеї ООП: інкапсуляція приховує внутрішній стан, абстракція залишає суттєве, наслідування повторно використовує/уточнює контракт, поліморфізм дає один інтерфейс для різних реалізацій.
- **Типова пастка:** Інкапсуляція — контроль доступу й інваріантів, а не просто поля private; наслідування не дорівнює повторному використанню за будь-яку ціну.
- **Розгорнута відповідь:** конспект вище визначає чотири принципи, їхню роль і межі застосування.
