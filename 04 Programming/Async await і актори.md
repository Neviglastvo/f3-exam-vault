# Async await і актори

> [!summary] Відповідь за 20–30 секунд
> Асинхронна модель представляє майбутній результат через future/promise/task та дозволяє await без блокування потоку; actor model ізолює стан і спілкується повідомленнями.

## Суть
- async/await — синтаксична модель побудови асинхронних операцій, а не гарантія паралельності.
- Non-blocking I/O особливо корисний для мережі, файлів та зовнішніх сервісів.
- Actor має ізольований стан і обробляє повідомлення; це зменшує потребу у shared-memory locks.
- Ізоляція стану та message passing полегшують масштабування у розподілених системах.

## Іспитовий фокус

- **Що запам'ятати:** Асинхронна модель представляє майбутній результат через future/promise/task та дозволяє await без блокування потоку; actor model ізолює стан і спілкується повідомленнями.
- **Типова пастка:** await не обов'язково створює новий потік; актор ізолює стан, але протоколи повідомлень усе одно треба проєктувати.
- **Можливі питання:** «Дайте визначення теми Async await і актори і поясніть ключовий механізм». «Яке головне обмеження або відмінність від пов'язаного поняття?»
