# UML

> [!summary] Відповідь за 20–30 секунд
> UML — стандартна графічна мова моделювання структури та поведінки системи; різні діаграми відповідають на різні питання.

## Суть
- Структурні: class diagram, component diagram, deployment diagram.
- Поведінкові: use case, sequence, state, activity, communication.
- Class diagram показує класи, атрибути, операції та зв’язки — асоціацію, агрегацію, композицію, узагальнення, реалізацію.
- Sequence diagram підкреслює порядок повідомлень; state — життєвий цикл станів; activity — потік робіт.
