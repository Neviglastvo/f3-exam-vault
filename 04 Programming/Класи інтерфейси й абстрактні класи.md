# Класи інтерфейси й абстрактні класи

> [!summary] Відповідь за 20–30 секунд
> Клас визначає структуру і поведінку об’єктів; інтерфейс формулює контракт, абстрактний клас може поєднувати контракт зі спільним станом та реалізацією.

## Суть
- Об’єкт — екземпляр класу; поля зберігають стан, методи визначають поведінку.
- Конструктор встановлює початковий коректний стан; деструктор/аналог механізму завершення пов’язаний з життєвим циклом ресурсів.
- Інтерфейс добре підходить для контракту без прив’язки до реалізації; абстрактний клас — для спільної базової реалізації.
- Узагальнення в моделюванні описує спільні властивості спеціалізованих типів.
