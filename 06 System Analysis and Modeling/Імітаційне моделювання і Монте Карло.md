# Імітаційне моделювання і Монте Карло

## Конспект розгорнутої відповіді

- Імітаційна модель відтворює хід подій у часі: стан системи, події, ресурси, черги та правила переходів. Її застосовують, коли формула для показника відсутня або надто спрощує процес.
- Для дискретно-подієвої моделі треба назвати: стан, календар подій, випадкові входи, правило зміни стану, початкові умови та показники результату. Без цього «імітація» лишається загальною назвою.
- Метод Монте-Карло генерує випадкові вибірки за заданим розподілом і за ними оцінює ймовірність, математичне сподівання або ризик. Точність оцінки зростає зі збільшенням кількості незалежних випробувань, але не виправляє помилковий розподіл входів.
- Потрібно відрізняти випадковість моделі від випадковості генератора: генератор дає псевдовипадкову послідовність; фіксоване зерно дозволяє відтворити запуск.
- Результат подають оцінкою, кількістю прогонів і мірою невизначеності. Один запуск не є статистичним доказом.
- **Перевірка:** [[Перевірені джерела для ІПММС#Системний аналіз, моделювання і верифікація]].

> [!summary] Відповідь за 20–30 секунд
> Імітаційне моделювання відтворює роботу системи в часі через події, стан і випадкові входи. Метод Монте-Карло повторює випадкові реалізації та оцінює шукану величину їх середнім і статистичною похибкою.

## Суть
- Структура імітаційної моделі: стан системи, календар подій або часовий крок, потоки сутностей, правила переходів, генератори випадкових величин, статистики результату.
- Алгоритм: ініціалізувати стан → вибрати наступну подію/крок → оновити стан і статистики → повторювати до умови зупинки → проаналізувати вибірку результатів.
- Для Монте-Карло потрібні розподіли вхідних випадкових величин, незалежні або контрольовано залежні реалізації й оцінка дисперсії результату.
- Кількість запусків зростає, доки довірчий інтервал або стандартна похибка не досягнуть потрібної точності. Потрібні також прогрів, незалежність циклів і фіксація seed для відтворення.

## Іспитовий фокус
- **Що запам'ятати:** імітація не «вгадує» майбутнє; вона оцінює поведінку заданої стохастичної моделі за сценаріями.
- **Типова пастка:** один запуск не є статистично надійною оцінкою; випадковий результат потребує повторних реалізацій.
- **Розгорнута відповідь:** конспект вище описує склад імітації, Монте-Карло, повторні прогони й подання невизначеності.
