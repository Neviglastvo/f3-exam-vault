# Основи системного моделювання

> [!summary] Відповідь за 20–30 секунд
> Модель — цільове спрощене подання об'єкта, яке зберігає властивості, потрібні для дослідження. Системний підхід вимагає явно задати мету, межу, припущення, входи, виходи, зв'язки та критерії адекватності.

## Суть
- Моделі класифікують як матеріальні й інформаційні; знакові, математичні, алгоритмічні, програмні; статичні/динамічні, дискретні/неперервні, детерміновані/стохастичні, лінійні/нелінійні.
- Вимоги до моделі: відповідність меті, достатня адекватність, простота, інтерпретованість, обчислювальна здійсненність, відтворюваність даних і припущень.
- Життєвий цикл моделі: постановка задачі → концептуалізація → формалізація → реалізація → верифікація/валідація → експеримент → документування й оновлення.
- Теорія прийняття рішень застосовує моделі для вибору альтернатив за визначеності, ризику або невизначеності; ситуативне моделювання оцінює сценарії «що буде, якщо».

## Іспитовий фокус
- **Що запам'ятати:** модель не копіює реальність, а відкидає несуттєве саме для поставленої мети.
- **Типова пастка:** математична модель не тотожна програмі: програма є реалізацією алгоритму, а алгоритм — способом обчислення за моделлю.
- **Можливі питання:** «Дайте визначення моделі та вимоги до неї». «Назвіть класифікації моделей». «Які етапи життєвого циклу моделі?»

## Самоперевірка
- **Поясни без нотатки:** чому одна модель може бути придатною для однієї мети й непридатною для іншої.
- **Назви 2–3 ключові поняття або кроки:** мета, припущення, адекватність, експеримент.
- **Порівняй із найближчою пов’язаною темою:** математична, алгоритмічна й програмна моделі.
