# Основи системного моделювання

## Конспект розгорнутої відповіді

- Модель — цілеспрямоване спрощене подання об'єкта, достатнє для конкретного питання. Вона не є «копією реальності»: її межі, припущення та точність залежать від мети.
- Матеріальні моделі відтворюють фізичні властивості; знакові — описують об'єкт текстом, схемою, формулою, таблицею або програмою. Математична модель задає змінні, параметри, зв'язки та обмеження.
- Основні етапи: визначити мету, об'єкт і критерії → виділити суттєві змінні та припущення → побудувати концептуальну й математичну моделі → оцінити параметри → перевірити модель → провести досліди → інтерпретувати результат у межах припущень.
- Адекватність означає придатність моделі для поставленої мети, а не повну тотожність об'єкту. Її оцінюють порівнянням прогнозів зі спостереженнями та аналізом чутливості.
- Для відповіді відокремлюй об'єкт, модель і експеримент над моделлю: об'єкт існує в реальності, модель описує його, експеримент дає наслідки припущень моделі.
- Системний підхід вимагає розглядати мету, межі, елементи, зв'язки, зовнішні впливи та ієрархію разом. Практичні вимоги до моделі: цільова адекватність, достатня точність, зрозумілі припущення, перевірюваність, економність і можливість змінити параметри.
- **Перевірка:** [[Перевірені джерела для ІПММС#Системний аналіз, моделювання і верифікація]].

> [!summary] Відповідь за 20–30 секунд
> Модель — цільове спрощене подання об'єкта, яке зберігає властивості, потрібні для дослідження. Системний підхід вимагає явно задати мету, межу, припущення, входи, виходи, зв'язки та критерії адекватності.

## Суть
- Моделі класифікують як матеріальні й інформаційні; знакові, математичні, алгоритмічні, програмні; статичні/динамічні, дискретні/неперервні, детерміновані/стохастичні, лінійні/нелінійні.
- Вимоги до моделі: відповідність меті, достатня адекватність, простота, інтерпретованість, обчислювальна здійсненність, відтворюваність даних і припущень.
- Життєвий цикл моделі: постановка задачі → концептуалізація → формалізація → реалізація → верифікація/валідація → експеримент → документування й оновлення.
- Теорія прийняття рішень застосовує моделі для вибору альтернатив за визначеності, ризику або невизначеності; ситуативне моделювання оцінює сценарії «що буде, якщо».

## Іспитовий фокус
- **Що запам'ятати:** модель не копіює реальність, а відкидає несуттєве саме для поставленої мети.
- **Типова пастка:** математична модель не тотожна програмі: програма є реалізацією алгоритму, а алгоритм — способом обчислення за моделлю.
- **Розгорнута відповідь:** конспект вище дає визначення, класи моделей, етапи побудови та критерій адекватності.

## Самоперевірка
- **Поясни без нотатки:** чому одна модель може бути придатною для однієї мети й непридатною для іншої.
- **Назви 2–3 ключові поняття або кроки:** мета, припущення, адекватність, експеримент.
- **Порівняй із найближчою пов’язаною темою:** математична, алгоритмічна й програмна моделі.
