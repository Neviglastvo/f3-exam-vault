# Динамічні моделі і диференціальні рівняння

## Конспект розгорнутої відповіді

- Динамічна модель описує, як стан системи змінюється в часі. Стан — мінімальний набір змінних, знання якого разом із входами дозволяє визначити подальшу поведінку моделі.
- Диференціальне рівняння пов'язує невідому функцію та її похідні. Для моделі першого порядку \(dx/dt=f(x,u,t)\) потрібні початкова умова (x(t_0)), закон зміни та, за потреби, вхід (u(t)).
- Аналітичний розв'язок отримують у замкненій формі лише для частини рівнянь. Чисельні методи обчислюють наближений розв'язок із кроком часу; менший крок не гарантує точності без оцінки збіжності й похибки.
- Рівноважний стан має нульову похідну. Його стійкість означає, що мале відхилення не відводить систему далеко або з часом згасає; це треба перевіряти за конкретною моделлю, а не за виглядом графіка.
- На екзамені назви змінні стану, параметри, початкові умови, вхідні дії та інтервал часу — тоді формула має зміст.
- Лінійне рівняння першого порядку зі сталими коефіцієнтами має вигляд \(x'+ax=b\); другого порядку — \(x''+ax'+bx=g(t)\). Для системи першого порядку зручно писати \(x'=Ax+Bu\). Нелінійна модель містить нелінійні функції стану або входу; суперпозиція для неї загалом не діє.
- **Перевірка:** [[Перевірені джерела для ІПММС#Системний аналіз, моделювання і верифікація]].

> [!summary] Відповідь за 20–30 секунд
> Динамічна модель описує зміну стану в часі. Диференціальне рівняння пов'язує невідому функцію та її похідні; початкові або крайові умови виділяють конкретний розв'язок із сімейства можливих.

## Суть
- Загальний стан можна задати $x(t)$, а закон еволюції — $\dot x=f(t,x,u)$. У лінійному стаціонарному випадку $\dot x=Ax+Bu$.
- Лінійне рівняння першого порядку зі сталим коефіцієнтом має форму $y'+ay=g(t)$; однорідний розв'язок визначає характеристичне рівняння, частинний — праву частину.
- Для другого порядку $ay''+by'+cy=g(t)$ характер рівня визначають корені характеристичного рівняння: два різні дійсні, кратний або комплексно-спряжені.
- Систему лінійних рівнянь першого порядку записують $\dot x=Ax+f(t)$; стійкість і тип траєкторій пов'язані зі спектром матриці $A$.

## Іспитовий фокус
- **Що запам'ятати:** порядок рівняння — найвищий порядок похідної; кількість початкових умов має відповідати порядку для задачі Коші.
- **Типова пастка:** нелінійність може бути в стані, вході або параметрах; не кожна модель із часом є лінійною.
- **Розгорнута відповідь:** конспект вище пов'язує стан, похідну, початкові умови, чисельний розв'язок і стійкість.
